Política de Privacidade

Esta política descreve como Arynelys Naryxel / NELYS trata dados quando o usuário utiliza o aplicativo e suas integrações.

1. Dados processados

O aplicativo pode processar arquivos escolhidos pelo próprio usuário, como vídeos, legendas, textos e metadados necessários para executar funções solicitadas.

2. Integrações e OAuth

Quando o usuário conecta uma plataforma externa, como TikTok, a autenticação é realizada pelo fluxo OAuth oficial da plataforma. O aplicativo não solicita nem armazena a senha da conta externa.

O aplicativo pode receber identificadores básicos da conta, tokens de acesso e de atualização, além de dados estritamente necessários às permissões concedidas pelo usuário.

3. Armazenamento

Os dados do aplicativo são armazenados localmente no computador do usuário. Tokens e segredos de integração são protegidos localmente utilizando os mecanismos de proteção disponíveis no Windows.

4. Conteúdo e publicação

Vídeos, legendas, descrições, hashtags e outros dados de publicação são enviados a uma plataforma externa somente quando necessário para uma ação solicitada e autorizada pelo usuário.

5. Compartilhamento de dados

Arynelys Naryxel não vende dados pessoais. Dados podem ser transmitidos às plataformas conectadas somente para executar funções autorizadas pelo usuário e conforme as APIs oficiais utilizadas.

6. Retenção e exclusão

O usuário pode remover integrações no aplicativo e apagar os dados locais correspondentes. Também pode revogar o acesso de Arynelys diretamente nas configurações de segurança da plataforma conectada.

7. Segurança

São aplicadas medidas técnicas para reduzir a exposição de credenciais, incluindo armazenamento local protegido e uso de OAuth em integrações compatíveis. Nenhum sistema é totalmente imune a riscos, por isso o usuário deve manter o sistema operacional e o aplicativo atualizados.

8. Serviços de terceiros

O uso de serviços externos também está sujeito aos termos e políticas de privacidade dessas plataformas.

9. Crianças

O aplicativo não é destinado especificamente a crianças e não busca coletar intencionalmente dados de menores.

10. Alterações

Esta política pode ser atualizada quando novas funções ou integrações forem adicionadas. A data da última atualização será indicada no início desta página.

11. Contato

Dúvidas ou solicitações podem ser enviadas por GitHub Issues.
