Suporte

Encontre o próximo passo.

Consulte as dúvidas frequentes ou registre um problema no repositório público da NELYS.

Contato direto

Para suporte e solicitações de privacidade, escreva para contato@naryxel.com. Para relatar problemas sem informações pessoais, também está disponível o repositório público abaixo.

Relatar um problema

Informe a versão do aplicativo, os passos executados e a mensagem de erro. Se anexar uma captura, remova informações pessoais e credenciais.

Abrir GitHub Issues

As issues são públicas e o GitHub pode exigir login para criar uma solicitação. Não publique tokens, senhas, Client Secret ou dados pessoais sensíveis.

Perguntas frequentes

A NELYS funciona no navegador?

O aplicativo descrito aqui é desktop para Windows. Este site oferece documentação, informações do produto e acesso às políticas.

O TikTok já aprovou a integração?

A integração está sujeita à análise do TikTok. Não apresentamos a existência do recurso ou deste site como prova de aprovação.

Preciso importar o mesmo vídeo outra vez?

Se o projeto já foi criado, procure seu nome e identificador na lista de Produções antes de importar novamente.

Pronto para publicar significa publicado?

Não. É o estado de preparação do conteúdo. A disponibilidade do vídeo na plataforma depende da etapa de envio e do processamento externo.

A estimativa de comissão é receita recebida?

Não. A NELYS distingue comissão estimada, conversões registradas e valores confirmados.

Onde encontro as condições de uso e privacidade?

A Política de Privacidade e os Termos de Serviço estão disponíveis publicamente, sem login.
